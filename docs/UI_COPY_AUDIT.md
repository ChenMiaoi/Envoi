# 界面文案审查

## 判断标准

删掉一句话后，如果用户仍能理解当前状态、完成操作并判断后果，就删除它。

- 标签和按钮已经表达的内容，不再用说明重复。
- 不在常规界面解释实现细节、开发边界或尚未提供的功能。
- 必要限制放在相关操作处；状态提醒只在对应状态下显示。
- 错误说明发生了什么，以及用户可以采取的下一步。
- 保留删除范围、未保存修改、冲突、权限和会影响操作结果的限制。
- 不把删去的说明统一搬进提示气泡；提示气泡也适用同一标准。

## 本次范围

审查五套语言字典（简体中文、繁体中文台湾、繁体中文香港、英文、日文），以及前端组件、桌面层和本地服务中直接写入的界面文案。覆盖欢迎页、项目管理、阅读与写作、素材、文献、版本与实验、Git 状态、编译、设置、AI 配置、通知和错误提示。

以修改前简体中文的 829 个词条为基准，删除 44 项、改写 57 项，另外将 11 项组件文案收进语言字典。修改后的字典有 796 项。数字按语义词条计数，不按五种语言重复计算；组件中直接删除的段落不计入这组数字。

用户文档、论文模板正文、示例研究内容、模型输入提示和第三方运行日志不属于产品界面措辞，不作改写。

## 主要处理

| 区域           | 处理                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| 设置           | 删除字体回退、Tab 不改写文本、配置存储方式等说明；保留项目继承状态和必要的输入格式示例。                        |
| Git            | 删除只读能力说明；无未保存修改时不显示磁盘与编辑器差异说明，有修改时显示“有未保存的修改，保存后更新 Git 状态。” |
| 版本与实验     | 删除首页和侧栏的重复介绍；“未提交修改不会带入”放在创建表单中；保存结果时保留目的地和提交要求。                  |
| 欢迎与项目管理 | 删除口号和重复按钮含义的说明；保留示例会创建副本、删除目录不可撤销、未保存内容等信息。                          |
| 文献           | 删除围绕研究思路的引导性措辞；使用“添加论文”“保存合并结果”等直接动作名称。                                      |
| 编译与素材     | 删除预览实现说明；保留编译错误、陈旧状态和定位限制，将静态分析结果表述为“未检测到引用”。                        |
| AI             | 删除运行时和配置实现的常驻说明；保留模型能力限制、项目继承状态和执行权限确认。                                  |
| 通知与错误     | 缩短成功提示；目录不可用时提示重新打开位置，不解释与故障无关的授权机制。                                        |

## 验证

已在真实 Electron 窗口检查编辑器设置、版本与实验页面和 Git 弹窗，并验证未保存提醒出现、保存后消失。构建、单元测试、静态检查和桌面回归用于检查词条引用、组件渲染及原有操作流程。
