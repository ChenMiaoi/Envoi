## 新增功能

- 新增项目限制模式：未信任的项目也可以阅读、编辑和保存文件；信任后启用编译、Git 和 AI 工具。可通过状态栏切换模式。
- 文件树显示 Git 状态颜色和标记，目录提示内部变动。
- 支持搜索并选择系统字体，提供字体预览，编辑器优先列出等宽字体。
- 字号和行高支持自定义输入、逐步调整和恢复默认，新增独立的文本预览行高设置。
- 设置页展示应用版本，支持检查更新并打开新版本下载页。
- 新增本地诊断日志，支持打开日志目录和导出诊断文件。

## 体验改进

- 通知、警告和错误统一使用右下角悬浮提示，支持关闭和自动消失。
- 滚动条随应用主题显示。
- 改进 CSV 表格显示，突出识别出的表头。
- 改进 Markdown 代码块的语法配色与显示。
- 精简界面中不影响理解的说明文字。

## 问题修复

- 区分移除最近记录与删除项目文件；移除当前项目记录时关闭项目，并处理未保存修改。
- 删除项目文件使用回收站，增加目录核对和关联工作区保护。
- 修复 Windows 路径别名可能导致受保护目录检查漏判的问题。
