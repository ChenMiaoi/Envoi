## 新增功能

- 代码文件支持语法高亮和语言服务器诊断；问题面板与底部状态栏可显示当前文件的语言服务状态。
- 阅读器新增 Markdown 富文本只读预览切换，文件树和阅读器标签可按文件类型显示图标。

## 体验改进

- 阅读、写作、论文库、版本与实验及设置页面采用留有间距的独立圆角区域。
- 底部悬浮栏居中显示，AI、语言服务和 LaTeX 编译器可直接在悬浮栏弹出的选项中切换。
- 工具配置按类别整理，代码高亮会跟随界面主题。
