## 新增功能

- 研究库支持跨来源搜索论文、查看嵌入式结果，并保留 DOI、arXiv 等来源信息。
- 版本与实验工作区支持创建、切换、提交和保存可追溯的实验结果。
- 阅读器支持 Markdown 实时编辑、文件树和标签页上下文菜单。

## 体验改进

- 统一桌面导航、状态栏和 PDF 预览工具栏，减少阅读与写作之间的切换干扰。
- 聊天界面按顺序展示推理和工具活动，并提供本地会话统计查看。
- 项目书目编辑、空状态、元数据和多语言界面提示更加清晰。

## 问题修复

- 修复 Windows 下工作区切换、项目选择、信任模式和窄窗口交互的状态与点击问题。
- 修复 Git 历史显示、工作区结果刷新、缓存迁移和研究库文件同步的一致性问题。
- 将本地 Windows 检查与 GitHub Windows CI 统一到同一个完整验证入口。
