## 新增功能

- 研究库支持导入项目 PDF、补全 DOI 元数据，并同步项目论文文件与研究档案。
- 工作区支持提交可复现的实验基线、创建实验并归档结果，保留结果来源与文件追溯关系。
- 聊天支持按顺序展示流式推理和工具活动，并可按需查看本地会话指标。

## 体验改进

- 新建研究项目时可以先记录研究笔记，再选择论文格式；阅读器会恢复上次的位置、页码和缩放比例。
- 项目书目支持直接编辑 BibTeX，并清晰区分项目来源与外部预览。

## 问题修复

- 修复跨平台 Git 历史记录的换行、提交主题和本地时区显示问题。
- 修复 Windows 下 Git worktree 监听与项目移入回收站时的文件占用问题。
- 修复工作区切换、实验元数据刷新、缓存迁移和研究库文件同步等场景下的状态一致性问题。
