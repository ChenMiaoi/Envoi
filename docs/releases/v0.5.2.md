## 体验改进

- 补全文献库、网页浏览与 PDF 阅读控件的五种界面语言翻译；切换语言后，已显示的错误提示同步更新。
- 语言服务器意外退出时显示故障状态并清除过期诊断，可直接重新连接并保留编辑草稿。

## 问题修复

- 撤销项目信任或停用语言插件时及时停止相关语言服务；修复关闭文档、切换工作区时尚未完成的启动请求继续运行的问题。
- 保存项目设置前检查配置文件和 Git 忽略规则的磁盘状态，避免覆盖外部修改；读取失败时不再按空配置写回。
- 网页 PDF 下载绑定发起下载的窗口与工作区，切换或关闭项目、撤销信任后取消下载，避免导入其他项目。
- 文献库数据库事务失败时撤销已完成的文件变更，减少部分导入和文件、记录不一致的问题，并保留检测到的外部修改。
- 修复从本地文件和缓存恢复 PDF 同步定位数据的问题，使 SyncTeX 定位在重新打开后可用。
- 单个内置语言插件的声明校验失败时隔离该插件，并在扩展页显示错误，避免阻断其他有效插件。
- 修复同版本 RC 安装无法发现正式版更新的问题，并修正 RC 版本排序。
- 修复繁体中文词典生成时的换行和术语覆盖，保证重新生成结果一致。
