## 新增功能

- 代码编辑器支持 Tab 接受补全、代码片段占位符和跳转到定义，并提供格式化、保存前格式化及代码检查。
- 扩展面板支持按需安装语言服务器及受支持的格式化、检查工具，展示安装进度并记住已检测到的工具路径。
- C/C++、Python 和 Rust 的代码检查支持当前文件的未保存内容，诊断与语言服务结果合并显示。

## 体验改进

- 更新代码编辑器配色、提示和诊断展示，使其与当前主题保持一致。
- 减少输入和 AI 流式回复引起的无关界面刷新，降低文件树、Git 状态、聊天记录和 PDF 校验的重复计算开销；离开写作页面后停止安排其代码检查。

## 问题修复

- 修复文件及目录重命名、删除和切换工作区时草稿处理不正确的问题，避免未保存内容丢失或旧草稿带入其他工作区。
- 无 LaTeX 主文件的项目现在可以正常保存项目设置。
- 修复保存与编译并发时可能漏掉编译请求的问题。
- 改善非 PATH 位置的工具发现、已安装语言服务器的重新连接，以及补全编辑和本地定义跳转。
