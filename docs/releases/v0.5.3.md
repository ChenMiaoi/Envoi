## 新增功能

- 新增远程 SSH 工作区：连接 Linux 主机后可直接编辑远程文件、运行语言工具与编译，内置连接管理与远程终端。
- 新增 WSL 工作区：浏览 WSL 发行版目录并自动准备运行环境，在 Windows 上编辑 Linux 项目。
- 项目导航按当前环境感知：项目切换与欢迎页统一提供本地、SSH 与 WSL 入口，连接可取消且失败时保留原项目。
- 缺少 clang-tidy、clang-format 等语言工具时，编辑器会提示从官方来源安装；安装 LLVM 工具链前会提示下载较大（约 1 GB）。

远程工作区目前支持 Linux SSH 主机和 Windows 上的 WSL；AI、文献库和实验工作区管理尚未接入远端。使用前请阅读 [SSH 指南](https://github.com/ChenMiaoi/Envoi/blob/v0.5.3/docs/REMOTE_SSH.md) 与 [WSL 指南](https://github.com/ChenMiaoi/Envoi/blob/v0.5.3/docs/WSL.md)。

## 体验改进

- 应用菜单与项目菜单重新设计：去除重复入口，显示当前项目、路径与未保存修改数量。
- Python 项目可一键创建 venv 或 uv 虚拟环境，语言服务优先使用项目环境。
- 移除编辑器焦点光晕并收紧代码内边距。

## 问题修复

- 项目关闭、切换或撤销信任时取消尚未完成的操作，避免迟到的结果写入新项目。
- 保留旧版本客户端的部分设置请求兼容性。
