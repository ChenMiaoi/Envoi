## 新增功能

- 新增内置 C/C++、Python 和 Rust 扩展管理：可按全局或项目启停，语言服务按工作区启动和释放。
- 扩展页分别展示工具链与语言服务器的可用状态；自动查找常见安装位置和多个版本，默认使用较新版本，也可选择其他版本或手动填写程序路径。C 和 C++ 共用一项语言服务器设置。
- Windows 版下载更新后可在应用内重启并安装。

## 体验改进

- 扩展卡片收起时只显示简要状态，展开后查看版本、路径和设置；部分工具可用时显示提醒。

## 问题修复

- 修复通用设置页无法用滚轮向下滚动的问题。
- 修复已安装的 `clangd` 在扩展页被误判为缺失，以及 macOS 上 `python3` 未被识别的问题；Rust 工具链中失效的 `rust-analyzer` 入口不再被误报为可用。
