## 新增功能

- 新增 Lean 4 扩展：支持安装 Lean/Lake、语法高亮、补全、悬停、定义跳转及证明诊断，可选择已有的格式化工具。
- 新增 RTL 扩展：支持 Verilog/SystemVerilog 编辑、slang-server 或 Verible 语言服务、Verible 格式化与检查，以及 Verilator 工程检查。可导入 Vivado 工程并调用已安装的 Vivado 进行编译和展开检查。
- 新增以 RISC-V 为重点的 ASM 扩展：内置指令与 CSR 补全、悬停、本文件跳转、语法高亮和保守格式化，支持按 ISA/ABI 配置 Clang 检查及可选 asm-lsp。仓库收录官方特权、非特权规范和固定版本源码，便于离线检索。

Lean、RTL 和 ASM 均有独立文件图标。工具安装仅向上游提供预编译包的平台开放；Vivado 及许可证需自行准备，Vivado 检查不等同于语言服务器。ASM 当前重点支持 GNU 风格的 RISC-V 汇编，Windows 暂无 asm-lsp 官方预编译安装包。详见 [Lean 指南](https://github.com/ChenMiaoi/Envoi/blob/v0.5.4/docs/LEAN.md)、[RTL 指南](https://github.com/ChenMiaoi/Envoi/blob/v0.5.4/docs/RTL.md) 和 [RISC-V 指南](https://github.com/ChenMiaoi/Envoi/blob/v0.5.4/docs/riscv/README.md)。

## 体验改进

- 代码编辑器自动补全括号和引号。
- SSH/WSL 项目接入论文库搜索、下载、PDF/BibTeX 导入、阅读笔记和引用，资料保存在当前远程项目内。SSH 论文库需要提供 `node:sqlite` 的 Node.js；WSL 自动准备的运行时已满足要求。
- WSL 连接前检查运行时安装依赖并提供提示；连接窗口保留当前环境和目录，远程编辑器隐藏尚未支持的 AI 输入区。

## 问题修复

- 修复远程工作区信任与扩展策略不同步的问题；关闭或断开工作区时取消工具操作，并为操作设置超时。
- 修复论文引用和编译依赖解析，改善参考文献与资源定位。
- 保留文献来源中的年份信息，并提示元数据冲突，避免不明确的来源覆盖。
