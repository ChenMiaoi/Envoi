## 新增功能

- 论文搜索支持调整来源优先级，并按主题相关性排列结果。
- 阅读器支持 Markdown 实时富文本预览；文件树支持复制文件和从系统拖入文件。

## 体验改进

- 新建项目对话框重新设计，论文搜索中的 Scholar 页面可在应用内打开。
- 向研究库添加论文时会下载可用 PDF，并明确提示下载结果。

## 问题修复

- 修复 Kimi For Coding 登录时授权链接和验证码无法显示的问题。
- 修复 Electron 程序文件尚未下载时，开发版无法启动的问题。
- 修复已有 Git 仓库的接入流程，避免将 Envoi 私有数据写入仓库历史。
