# Remote SSH

Envoi 的内置 `envoi.remote-ssh` 扩展将远程目录接入现有文件树、编辑器、保存与 Git 视图。代码与开发工具运行在远端；窗口、偏好和未保存草稿保留在本机。

## 连接

从项目菜单选择「远程 SSH 工作区」，或在「设置 → 扩展 → Remote SSH」中打开连接管理。

欢迎页与项目名称切换菜单也提供连接入口。SSH 和 WSL 分别保留输入；关闭连接窗口会取消本次连接。项目切换先准备新目录，加载失败时保留原项目。入口与后续设计见 [项目与环境导航](WORKSPACE_NAVIGATION.md)。

- 本机需要 PATH 中可用的 OpenSSH `ssh`。
- 首版远端支持 Linux，需要 PATH 中的 Node.js 22 或更新版本，以及 `sh`、`head`、`sha256sum` 等常规系统工具。
- 交互终端需要远端 Python 3；语言补全需要在远端安装 clangd、rust-analyzer 或 Python 语言服务器。LaTeX 编译需要远端的对应工具链。
- 主机填写 SSH 配置别名或 `user@host`；目录填写绝对路径。端口留空时遵循 SSH 配置。可指定本机 SSH 配置文件的绝对路径，否则使用系统默认配置。密钥、跳板机及其他连接选项在系统 SSH 配置中设置。
- SSH 主机指纹确认、私钥口令等提示显示在应用内。密码与口令不写入连接配置；主机密钥由 OpenSSH 校验。

首次连接会将随桌面应用构建的服务脚本上传到远端 `~/.envoi/remote-server/<SHA256>.cjs`，校验内容后启动。该版本要求用户已安装 Node.js，不自动安装系统运行时。

打开目录后仍使用原有编辑和保存操作。首次运行语言服务、Git、编译或终端前，需要通过现有项目信任提示。文件读写始终限制在远程根目录内，指向根目录外的符号链接不可访问。

## 工作区与恢复

所有远程操作通过同一个窗口所属的 SSH 工作区连接分发；远端项目服务复用本地文件保存、LSP、语言工具、Git 和编译实现。未接入的操作会明确报错，不会把远程路径交给本地工具执行。

连接身份包含主机、显式端口和目录。不同主机上的相同路径具有不同项目和草稿身份。远端工具检测使用远端环境，不继承本机可执行文件路径。

SSH 承载按请求编号分发的 JSON 消息；终端数据、文件事件和语言诊断使用事件消息。标准输出只承载协议，启动错误保留在标准错误中。远端服务仅监听当前用户的 Unix socket，不对网络开放额外服务端口。

客户端使用心跳检测断线，最多自动重连三次。远端代理断开后，无界面项目服务保留五分钟，允许重新连接并保留交互终端。主动断开会停止终端、语言服务和当前编译。关闭应用时也会释放当前连接。

终端位于可调整高度的底部面板，可以与编辑器同时使用。「隐藏终端」保留远端终端，「结束终端」显式停止它。Git 历史独立于尚未支持的远端实验工作区管理。

断线期间仍可编辑草稿，但保存不会报告成功。写请求不会自动重放；保存使用旧文件内容作为比较基线，检测到外部修改时保留草稿并返回冲突。重启应用先恢复本地草稿，再通过连接管理重新连接。

## 当前边界

- 已接入：现有文件树与文本编辑、文件增删改名及内部复制、带冲突检测的保存、资源预览、远端文件监听、LSP、格式化/检查、Git 状态与历史、LaTeX 编译调用、交互终端。
- 语言工具通过远端 PATH 和既有环境发现规则选择；远端工具的应用内安装、手动路径及版本选择尚未接入。扩展页展示远端检测结果，工具可通过终端安装。
- 论文库支持搜索、浏览下载、PDF/BibTeX 导入、笔记和引用。资料保存在当前远程项目内，Git worktree 使用独立资料库，不跨越连接授权的目录。搜索和下载请求由桌面端发起。
- 论文库需要远端 Node.js 提供 `node:sqlite`；不具备该模块的旧运行时会显示升级提示，其他文件与工具功能不受影响。WSL 自动准备的固定运行时已包含该模块。
- AI 项目操作、实验工作区管理、外部拖放导入和整项目删除尚未接入远端；远程编辑器隐藏不可用的 AI 输入区。
- 当前目录加载沿用项目快照方式，远端限制为 50,000 个条目、24 MB 文本总量、单个文本 5 MB、单个读取文件 32 MB。大仓库请打开较小子目录；后续再接入按需文件加载。
- 不承诺远端机器重启后恢复进程；本地草稿恢复与远端进程存活是独立机制。
- 不兼容 VS Code/Zed 可执行扩展，不依赖它们的服务端发行包。

## 验证

`npm run ci:check` 执行完整本地检查，包括 SSH 参数隔离、协议请求、断线拒绝、保存冲突及路径边界的自动测试。

真实 SSH 验收单独运行：

```sh
npm --prefix app run build:desktop
npm --prefix app run test:remote
```

真实测试需要 Docker 和 OpenSSH。测试创建仅绑定本机回环地址的 Linux SSH 容器，使用一次性密钥和独立 known_hosts，检查服务部署、主机密钥错误、文件读写、信任、clangd 补全/诊断/定义跳转、PTY、Git 和断线重连。容器和测试密钥在退出时清理。普通单元测试不能代替这项验收。
