# PaperDesk application

This directory contains the React/Vite interface, local Node adapters, and tests. See the [root README](../README.md) and [contribution guide](../CONTRIBUTING.md) for setup.

Commands can run directly here (`npm ci`, `npm run dev -- --host 127.0.0.1`, `npm test`, `npm run build`) or through the root npm wrappers. The paper example lives in [`../examples/demo/`](../examples/demo/). Architecture and local capability notes live in [`../docs/`](../docs/).
